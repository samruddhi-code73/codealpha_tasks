# Amazon Products Data Visualization Project

## Project Overview

This project focuses on transforming raw Amazon product data into meaningful visual insights using Python visualization libraries.

The dataset was obtained from Kaggle and contains information related to product categories, prices, discounts, ratings, and customer reviews.

The main objective of this project is to create clear, informative, and visually appealing charts and dashboards that help understand trends, patterns, and anomalies in Amazon product data.

# Objectives

* Transform raw data into visual formats
* Create meaningful charts and graphs
* Identify trends and patterns visually
* Detect anomalies and outliers
* Build a visualization dashboard
* Generate insights using visual storytelling

# Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* VS Code

# Visualizations Created

## 1. Distribution of Product Ratings

Purpose:
To understand overall customer satisfaction trends.

### Insight

Most products are rated between 4.0 and 4.5, indicating generally positive customer feedback.

## 2. Discount Percentage Distribution

Purpose:
To analyze product discount trends.

### Insight

Many products offer moderate-to-high discounts as a marketing strategy.

## 3. Top Product Categories

Purpose:
To identify the most common product categories.

### Insight

Electronics and accessories categories dominate the dataset.

## 4. Price Outlier Boxplot

Purpose:
To detect anomalies in product pricing.

### Insight

Several premium products create significant price outliers in the dataset.

## 5. Correlation Heatmap

Purpose:
To analyze relationships between variables.

### Insight

Discount percentage shows a weak relationship with customer ratings.

## 6. Price vs Rating Scatterplot

Purpose:
To analyze whether expensive products receive better ratings.

### Insight

Higher product prices do not necessarily guarantee higher ratings.

# Dashboard

A combined visualization dashboard was created using multiple charts to provide a complete overview of the dataset.

Dashboard includes:

* Ratings Distribution
* Discount Distribution
* Top Categories
* Price Outliers

# Key Findings

* Most products receive ratings above 4.0
* Electronics-related products dominate the dataset
* Significant pricing outliers exist
* Discounts do not strongly influence ratings
* Customer feedback is generally positive
