# Unemployment Analysis in India

##  Overview
This project analyzes unemployment trends in India using Python. The analysis focuses on identifying unemployment patterns, regional differences, and the impact of COVID-19 through data visualization and exploratory data analysis.

##  Objectives
- Clean and preprocess unemployment data.
- Analyze unemployment trends over time.
- Study the impact of COVID-19 on employment.
- Compare unemployment rates across different states.
- Generate meaningful insights through visualizations.

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

##  Key Findings
- Unemployment rates increased significantly during the COVID-19 period.
- Different states showed varying unemployment levels.
- Urban areas experienced greater fluctuations in unemployment.
- Monthly trends indicate seasonal variations in employment.
- Labour participation rates influenced unemployment patterns.

##  How to Run
1. Install required libraries:
    pip install pandas numpy matplotlib seaborn plotly
2. Run the script:
    python Analysis.py

## Conclusion

The analysis highlights the impact of COVID-19, regional disparities, and seasonal trends in unemployment. These insights can help in understanding employment challenges and supporting policy decisions.
